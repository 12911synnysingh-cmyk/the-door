# The Door

A lightweight, responsive, single-page web app for moments of curiosity.

## Run it

Open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Included

- A tap-friendly 3D CSS door opening animation
- 75 unique bilingual cards based on daily actions, deep thoughts, and cosmic perspective
- English (default) and Hindi language switching
- Three door openings per local calendar day, persisted in the browser and reset automatically after midnight
- Responsive mobile-first layout
- Standalone app icon and web manifest
- No framework, build step, or external runtime dependency
